# תהליך העבודה של עיצוב ומוצר

כל פיצ'ר או בעיה עוברים כאן שישה שלבים. כל שלב משאיר מסמך קצר אחד, ורק כיוון שאושר בשער ההחלטה ממשיך לפיתוח.

| שלב | המסמך | מה הוא כולל | מי מוביל |
| --- | --- | --- | --- |
| 1. מסגור | `brief.md` | הבעיה, למי היא חשובה, התוצאה הרצויה, מסגרת זמן ומה לא עושים | מוצר |
| 2. חקר וסינתזה | `insights.md` | תובנות ממשתמשים עם ראיות ורמת ביטחון | עיצוב ומוצר |
| 3. כיוונים | `options.md` | 2 עד 4 כיוונים עם קישורי Figma, יתרונות וחסרונות | עיצוב |
| 4. שער החלטה | `decision.md` | מה נבחר, מה נדחה, למה ומי אישר | מוצר, עיצוב ופיתוח |
| 5. מפרט | `spec.md` | מסכים, מצבים, מקרי קצה וקריטריוני קבלה | עיצוב |
| 6. העברה לפיתוח | `handoff.md` | נוצר אוטומטית: סיכום, קישורים וקריטריונים לפיתוח | פיתוח |

## איפה הכל נמצא

- `explorations/` — תיקייה לכל פיצ'ר, עם המסמכים של כל השלבים.
- `decisions.md` — יומן כל ההחלטות שהתקבלו.
- `context.md` — הקשר מוצרי קבוע: המוצר, המשתמשים, עקרונות העיצוב.
- `templates/` — התבניות. אפשר לשנות אותן לפי הצורך של הצוות.

## בלי טרמינל

לא צריך לעבוד עם טרמינל או Git כדי להשתתף בתהליך.

- **עריכה ב-GitHub:** פותחים את הקובץ באתר GitHub, לוחצים על סמל העיפרון, כותבים ושומרים.
- **כתיבה במקום אחר:** אפשר לכתוב ב-Figma או במסמך רגיל, ומישהו מהפיתוח מעתיק לכאן.
- **ההערות בתוך `<!-- -->`** הן הנחיות. אפשר להשאיר אותן; הן לא נחשבות כתוכן.
- **לא משנים את שמות הכותרות** (`##`), כי הבדיקה האוטומטית מחפשת אותן.

## למי שמריץ את הכלי

```
{{cli}} new "שם קצר של הבעיה" --slug short-name   # פתיחת תהליך חדש
{{cli}} status                                    # איפה כל תהליך עומד
{{cli}} next <id>                                 # מעבר לשלב הבא, אחרי בדיקה
{{cli}} check                                     # בדיקה של כל המסמכים
{{cli}} archive <id>                              # העברה לארכיון אחרי שהפיצ'ר נבנה
```

## עם סוכן AI (אופציונלי)

ב-Claude Code או ב-Cursor יש פקודה לכל שלב: `/d2s-frame`, `/d2s-research`, `/d2s-options`, `/d2s-decide`, `/d2s-spec`, `/d2s-handoff`. הסוכן עוזר לנסח ולסכם, אבל לא ממציא נתונים ולא מאשר החלטות.

השתמשו רק בכלי AI שהארגון אישר. אל תכניסו מידע פנימי לכלי AI חינמי שפתוח לציבור.
